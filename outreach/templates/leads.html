How should my file look?

The first row must have column names. Only an Email column is required. These are recognised automatically: Email, First Name, Last Name, Company (or a single Name column). Every other column (e.g. City, Website, Icebreaker) becomes a variable you can use in emails, like {{ '{{city}}' }} or {{ '{{icebreaker}}' }}.

From Excel: File → Save As → CSV UTF-8. From Google Sheets: File → Download → CSV. Duplicates and blocklisted emails are skipped automatically.
